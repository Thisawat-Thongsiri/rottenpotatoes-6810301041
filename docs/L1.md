## แบบฝึกหัด: ./mvnw dependency:tree

| library / starter | มีไว้ทำอะไร |
|---|---|
| spring-boot-starter-test | ชุด starter มาตรฐานของ Spring Boot ที่รวบรวมไลบรารีสำหรับเขียนและรันการทดสอบ (เช่น JUnit, AssertJ, Mockito) ไว้ให้พร้อมใช้งาน |
| junit-jupiter | เฟรมเวิร์กหลัก (JUnit 5) สำหรับเขียนและรัน Unit Test ในภาษา Java เช่น การใช้ `@Test` และคำสั่งตรวจสอบผลลัพธ์อย่าง `assertEquals` |
| assertj-core | ไลบรารีสำหรับเขียนคำสั่งตรวจสอบเงื่อนไข (Fluent Assertions) ให้อ่านเข้าใจง่ายเหมือนภาษาคน และแสดงรายละเอียดความแตกต่างได้ชัดเจนเมื่อเทสต์ไม่ผ่าน |
| mockito-core | ไลบรารีสำหรับสร้างอ็อบเจกต์จำลอง (Mock) เพื่อจำลองการทำงานของส่วนอื่น ทำให้ทดสอบโค้ดแต่ละส่วนแยกกันได้โดยไม่ต้องต่อฐานข้อมูลหรือระบบภายนอกจริง |
| spring-boot-starter | starter พื้นฐานหลักของ Spring Boot ที่รวมระบบ Auto-configuration และระบบ Logging มาให้ในโปรเจกต์ |
